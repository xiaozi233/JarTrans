# JarTrans 界面设计规范（扁平化）

本轮 UI 优化以「扁平、简洁、统一」为目标，**不改动任何功能与交互结果**，
只调整视觉表达与操作引导。结构规则集中在 `base.css`，配色集中在
`light.css` / `dark.css` 的调色板；`ThemeTokenTest` 与
`StateKeyConsistencyTest` 守护令牌与结构的一致性。

## 1. 配色

### 1.1 设计原则

- **单层表面**：窗口底（`-jr-bg`）→ 面板（`-jr-surface`）→ 输入/悬停（`-jr-field-bg` /
  `-jr-surface-alt`）三级，层级只靠 1px 边框（`-jr-border`）与背景明度差表达，
  **不使用投影**（弹出层同样只保留边框）。
- **一个主色**：靛蓝 `-jr-accent` 只用于主操作（打开 Jar、保存译文、主按钮）
  与选中/焦点，其余按钮一律中性；避免「到处是蓝按钮」。
- **语义色独立**：类状态色（`-jr-state-*`）表达翻译进度；新增危险色
  `-jr-danger` / `-jr-danger-hover` / `-jr-danger-soft` 专用于不可逆操作
  （删除词典/词条），与主色不混用。
- **对比度**：正文 `-jr-fg` 对背景 ≥ 7:1；次要文字 `-jr-muted` 仅用于说明文字
  （12px），不承载关键操作文案。

### 1.2 本轮具体改动

| 项 | 之前 | 之后 |
|---|---|---|
| 弹出层阴影 | `dropshadow(gaussian, …)` ×3（下拉/右键菜单/提示气泡） | 移除，仅保留 1px 边框 |
| 危险操作 | 与普通按钮同色 | `-jr-danger` 描边 + hover 淡红底（`删除`/`删除选中`） |
| 工具栏按钮 | 全部带边框，主次不分 | 次要按钮「幽灵」样式（无边框，hover 才出底色），仅「打开 Jar」保留主色填充 |
| 表格 | 斑马纹 + 选中/悬停 | 去斑马纹，仅保留 hover / 选中反馈（IDE 式扁平表格） |

## 2. 留白（8px 栅格）

统一采用 **4 / 8 / 12 / 16** 的间距刻度，不再出现 6、7、10 等零散值：

| 区域 | 间距 | 位置 |
|---|---|---|
| 工具栏 | `6 8`（上下/左右），按钮间距 6 | `base.css` `.tool-bar`，`main_view.fxml` |
| 左栏内边距 | 8，控件行间距 8 | `main_view.fxml` 类列表 VBox |
| 图例 | 横 12 / 纵 4 | `main_view.fxml` `legendBox` |
| 页签 | `6 14`，头部区 `4 8 0 8` | `base.css` `.tab-pane .tab` |
| 状态栏 | `5 12` | `base.css` `.status-bar` |
| 对话框 | 根容器 12，区块间距 10 | `PreferencesDialog` / `AppWindow` |
| 空状态 | 标题与提示 6，整体水平居中 | `EmptyStates` |

组件圆角收敛为两级：**控件 4px、容器/弹出层 6px**（此前 6/8 混用）。

## 3. 字体层级

| 层级 | 规格 | 用途 |
|---|---|---|
| 区块标题 | 15px / bold / `-jr-fg` | `.section-title`（首选项各分区） |
| 面板头 | 12px / bold / `-jr-muted` | `.pane-header`（类列表） |
| 正文 | 13px / regular / `-jr-fg` | 默认控件文本 |
| 表格表头 | 12px / bold / `-jr-muted` | `.column-header .label` |
| 说明/提示 | 12px / `-jr-muted` | `.hint`、`.empty-hint`、状态栏 |
| 空状态标题 | 14px / bold / `-jr-fg` | `.empty-title` |
| 代码 | 13px monospace | 源码视图（`Consolas`） |
| 译文编辑区 | 13px 界面字体（非等宽） | `.translation-editor`（中英混排更易读） |

此前首选项区块标题用内联样式（12px、主色）且与正文区分不足，现统一为
15px 加粗正文色，形成「区块标题 > 正文 > 说明」三级层次。

## 4. 组件样式（扁平化细节）

- **按钮**：默认白底 + 1px 边框，hover 换底色，pressed 加深；主按钮（`.accent`）
  实色填充；工具栏次要按钮走幽灵样式；破坏性操作 `.danger`。
- **输入框 / 下拉 / 文本域**：4px 圆角，默认 1px 边框，hover 加深，focused 变主色
  边框（不发光）；下拉弹层去阴影、4px 内边距、项圆角 4。
- **表格/列表/树**：容器 6px 圆角 + 边框；行高 30px；表头 30px、字重 bold；
  去斑马纹，hover 淡主色、选中主色淡底。
- **页签**：下划线式（选中 2px 主色下划线 + 加粗），无背景块。
- **菜单**：弹出层 6px 圆角 + 边框；菜单项 4px 圆角，hover 淡主色底。
- **滚动条**：12px 宽，透明轨道 + 8px 圆角滑块（保留最短长度皮肤）。
- **提示气泡**：4px 圆角 + 边框，去阴影。
- **空状态**：统一 `EmptyStates.create(标题, 提示)`（14px 粗标题 + 12px 说明），
  已覆盖译文表格、源码列表、搜索窗口、词典窗口、失效条目、类树。

## 5. 操作逻辑与反馈改进（参照实际界面）

### 5.1 流程精简

- **工具栏精简**：只保留 `打开 Jar`（主色）｜`导出汉化 Jar`｜词典下拉｜
  `搜索框+搜索…`｜`首选项…` 五组；导入/导出语言包等低频动作收进「文件」菜单，
  工具栏从 11 个控件降到 8 个，视觉落点集中在主流程。
- **类树空状态**（`main_view.fxml` `treePlaceholder`）：未打开 jar 时显示
  「先打开一个 Jar / 或点工具栏的「打开 Jar」」；打开后过滤无结果时提示
  「没有匹配的类 / 调整过滤词或状态筛选」——替代此前一整块空白树。
- **译文表格空状态**（`EditorPane`）：未选类显示「从左侧选择一个类…」；
  选中类但无字符串时提示可勾选「显示内部 UTF8 条目」。
- **源码页空状态**（`SourcePanel`）：未选类时提示「在左侧选择类后自动反编译；
  双击翻译行可直接跳转」。
- **搜索窗口**（`SearchWindow`）：空表提示「输入关键词开始搜索 / 范围可选…」。

### 5.2 操作提示与反馈

- **工具栏 tooltip**：每个动作补一句结果描述（如「导出汉化 Jar：把当前译文写回
  jar（写回前逐类校验结构）」），悬停即可理解，不必先点。
- **可用性状态**：未打开 jar 时工具栏的「导出汉化 Jar / 导入语言包 / 导出语言包」
  置灰（`MainApp.updateJarDependentActions`），替代此前点击后才弹出
  「请先打开一个 jar 文件」。
- **后台操作可视化**：导出/导入/批量填充等后台任务执行期间，状态栏进度条显示
  不确定态动画，结束后恢复为翻译进度（`BackgroundOps` 的 busy 回调）。
- **菜单快捷键同步**：搜索菜单项文案中的快捷键由 `refreshMenuShortcutHints()`
  按当前绑定实时生成，用户自定义快捷键后不再显示过期提示。
- **危险操作视觉区分**：词典管理「删除」、词条「删除选中」改为危险样式，
  与确认对话框配合，降低误触。
- **输入引导**：类名过滤框、词典搜索框、源码搜索框、译文编辑区均补 placeholder，
  说明「输入什么、会发生什么」。

### 5.3 导航结构

- 保持「左类树 / 右翻译+源码双页签 / 底部状态栏」的经典三栏结构不变；
  页签文案去掉手工空格留白（改由 CSS padding 控制），视觉更整齐。
- **菜单 8 → 6**：`文件`（打开/导出/语言包导入导出/失效条目/首选项/退出）、
  `词典`、`类状态`、`查看`（源码查看与缓存清理、显示开关、主题）、`搜索`、`帮助`。
  语言包与源码不再单列顶级菜单，减少顶部横向扫描。

## 6. 技术说明与已知约束

- **工具栏由 `ToolBar` 改为样式化 `HBox`**：JavaFX `ToolBar` 的皮肤容器存在
  looked-up color 解析边界（其内部按钮无法继承 `.root` 的自定义令牌，
  深色主题下文字变为黑色不可读）。改用 `HBox` + `.tool-bar` 类后令牌正常解析；
  代价是失去溢出菜单，因此主窗最小宽度由 980 提到 1100（默认 1320）。
- 空状态与提示文案统一使用样式类（`.empty-title/.empty-hint/.hint/.section-title`），
  新增界面元素请复用，不要在代码里写内联样式。
- **未做**：图标体系（当前为纯文字按钮，避免引入图标字体依赖）、界面文案 i18n
  资源化（中文硬编码，后续可接入 ResourceBundle）。

## 8. 源码页（补充）

「源码」页展示所选类的**反编译结果（只读）**，用于对照原文/译文上下文：
顶部 `文件：` 下拉在类与内部类之间切换，`查找：` 在当页源码中定位字符串（回车跳到下一处），
右侧固定显示「反编译源码（只读）」状态；页签悬停有用途说明。
**禁止在界面展示反编译缓存的绝对路径**——它不仅无意义，还会因文本过长挤压同排控件
（曾导致按钮被省略成「…」）。长文本一律设置 `minWidth=0` + 省略号，只省略自身。
